               POTENTIAL JUDGE QUESTIONS & BULLETPROOF ANSWERS
================================================================================

Q1: "How does the multimodal screenshot feature work without sending images to the cloud?"
A1: "We use Ollama's native multimodal API with gemma4:e2b. We encode the uploaded
     screenshot as a base64 tensor array and pass it directly to the local model on
     port 11434. Gemma 4 reads the visual pixels, performs OCR on the stack trace,
     and returns structured JSON without any byte ever leaving this machine."

Q2: "What happens if a repo doesn't have a CONTRIBUTING.md file?"
A2: "GitCompass has a smart detection algorithm. If no CONTRIBUTING.md exists, it
     automatically falls back to universal open-source standards — Conventional
     Commits, test plan specifications, and clean scope verification — ensuring
     every PR is clean and structured regardless of repo setup."

Q3: "How do you prevent AI hallucinations in file paths?"
A3: "We use Grounded AST Verification. Every suspected file and line citation
     returned by the model is cross-referenced in memory against the actual recursive
     GitHub file tree. If a path doesn't exist, it is filtered out."

Q4: "Can this scale to massive production codebases?"
A4: "Yes! We implement in-memory caching with TTL, URL segment escaping, and
     tree pruning that caps ingestion to the top architectural directories so
     even 50,000-file repos like next.js or react process in seconds."
