*🎯 COMMON JUDGE QUESTIONS & SHORT ANSWERS:*
━━━━━━━━━━━━━━━━━━━━━━━━━━

*Q1: How does vision work locally without cloud?*
*Ans:* We use Ollama's vision API with local `gemma4:e2b`. We pass image pixels directly into the local model on port 11434. No data ever leaves the laptop.

*Q2: What if a project has no CONTRIBUTING.md file?*
*Ans:* GitCompass detects this automatically and falls back to universal open-source standards (like Conventional Commits and clean test plans).

*Q3: How do you prevent AI from making up fake files?*
*Ans:* We use Grounded AST Verification. Every file name the AI mentions is verified against the real GitHub file tree. If it doesn't exist, it gets removed.

*Q4: Can it handle huge projects like React or Next.js?*
*Ans:* Yes! We use memory caching and folder pruning so even 50,000-file repos are analyzed in seconds.
